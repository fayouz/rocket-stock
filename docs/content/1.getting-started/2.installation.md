## Docker Compose

```bash
docker compose up -d --build
```

- Application : http://localhost:4100 (la configuration initiale crée le compte administrateur)
- API et documentation OpenAPI : http://localhost:9100/api/docs

## Développement sans Docker

```bash
# backend (PHP 8.4, PostgreSQL)
cd backend && composer install
php bin/console lexik:jwt:generate-keypair
php bin/console doctrine:migrations:migrate
php bin/console app:demo:seed            # avec DEMO_MODE=1 : lieux, catalogue, stock et magasins de démo
php -S 127.0.0.1:9000 -t public

# frontend
cd frontend && npm install && npm run dev -- --port 4000
```

## Intégrations

- `ROCKET_PLACE_URL` + `ROCKET_PLACE_TOKEN` (`rpl_…`) : lieux et stock de Rocket Place ; vide : lieux locaux (mode autonome).
- `AMAZON_ASSOCIATE_TAG` : identifiant Partenaires Amazon ajouté aux paniers pré-remplis ; vide (défaut) : aucun.
- `STOCK_ALERT_EMAILS` : destinataires des alertes de stock bas (virgules) ; vide : aucune alerte.
- `ROCKET_MAILER_URL` + `ROCKET_MAILER_TOKEN` (+ `ROCKET_MAILER_MAILBOX`, `ROCKET_MAILER_SENDER`) : e-mails ; vide : démo.
- `ROCKET_MAILER_URL`, `ROCKET_MAILER_TOKEN`, `ROCKET_MAILER_MAILBOX`, `ROCKET_MAILER_SENDER` : alertes de stock bas via Rocket Mailer (voir [Stock](/usage/stock)).
- Le worker (`php bin/console messenger:consume async scheduler_default`) lance les tâches récurrentes (santé des services, e-mails quotidiens).

En mode suite (`ROCKET_AUTH_URL` + `ROCKET_AUTH_CLIENT_SECRET`), Rocket Place et Rocket Mailer sont appelés avec des jetons Rocket Auth ; les jetons statiques servent de repli.
