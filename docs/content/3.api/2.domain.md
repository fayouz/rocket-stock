Toutes les routes demandent un utilisateur connecté (jeton JWT) ou une application externe (`Authorization: Bearer rst_…`, avec ou sans `X-Impersonate-User`). Une application **pour elle-même** (sans impersonation) a accès à toutes les routes ci-dessous (`StockAccessVoter`, `StockScopeGuardListener`). JSON : `Accept: application/json`.

Droits : **lecture**, niveaux, mouvements et paniers pour tout utilisateur ; **catalogue, magasins, équipements, emplacements, lieux locaux et suppressions de paniers** pour les administrateurs (et les applications).

`{placeId}` est un UUID : celui de Rocket Place quand il est configuré, sinon celui d'un lieu local. Les identifiants d'article ou de lieu s'acceptent seuls ou en IRI (`/api/stock-items/<uuid>`, `/api/places/<uuid>`).

## Lieux

| Méthode | Route | |
|---|---|---|
| GET | `/api/places` | Liste `{"id", "name", "source": "local" \| "place"}` |
| POST | `/api/places` | `{"name"}` (autonome seulement) |
| GET · PATCH · DELETE | `/api/places/{placeId}` | Un lieu ; PATCH `{"name"}`, DELETE (autonome) |
| GET · POST | `/api/places/{placeId}/locations` | Emplacements ; POST `{"name"}` |
| DELETE | `/api/locations/{id}` | Supprime un emplacement, ses niveaux et mouvements |

## Niveaux (compatible Rocket Place)

| Méthode | Route | |
|---|---|---|
| GET | `/api/stock-levels` | `?place=/api/places/<id>`, `?item=`, `?location=`, `?state=ok\|low\|empty`. Chaque niveau : `id`, `place` et `item` (IRI), `level`, + `name`, `quantity`, `threshold`, `target`, `location` |
| POST | `/api/stock-levels` | `{"place", "item", "location"?, "level"?, "quantity"?, "thresholdOverride"?, "targetQuantity"?}` : 201, ou 200 si déjà suivi |
| GET · PATCH · DELETE | `/api/stock-levels/{id}` | PATCH `{"level"}` comme Place, ou `quantity`, `thresholdOverride`, `targetQuantity` |
| GET · POST | `/api/places/{placeId}/stock` | Niveaux d'un lieu (tous emplacements) ; POST comme `/api/stock-levels` |

## Mouvements

| Méthode | Route | |
|---|---|---|
| GET | `/api/movements` | `?place`, `?item`, `?type`, `?usage`, `?origin`, `?externalRef`, `?from`, `?to` (AAAA-MM-JJ), `?limit` |
| POST | `/api/movements` | `{"item", "placeId", "location"?, "type": "in" \| "out" \| "consume" \| "transfer" \| "adjust", "quantity", "reason"?, "externalRef"?, "origin"?, "originApp"?, "usage"?: "rental" \| "personal", "unitCost"?, "occurredAt"?, "toPlaceId"?, "toLocation"?}` ; ou une liste (tout ou rien). `externalRef` déjà connue : 200 avec le mouvement existant |
| GET | `/api/movements/{id}` | |

```bash [Terminal]
# Rocket Clean, en fin de ménage : ce qui a été consommé (rejouable sans risque)
curl -X POST https://stock.example.org/api/movements \
  -H "Authorization: Bearer rst_…" -H "Content-Type: application/json" -H "Accept: application/json" \
  -d '[{"item":"<uuid café>","placeId":"<uuid lieu>","type":"consume","quantity":4,"origin":"clean","externalRef":"cleaning:<id>:cafe"}]'
```

## Courses

| Méthode | Route | |
|---|---|---|
| GET | `/api/shopping-list` | Calculée : `lines` (`suggestedQty`, `store`, `estimatedCost`…), `byStore`, `estimatedTotal` ; `?place`, `?subscription=0` |
| GET · POST | `/api/shopping-carts` | POST (`?place=` ou tous les lieux) crée un panier (422 si rien à acheter) ; GET `?status`, `?place` |
| GET · PATCH · DELETE | `/api/shopping-carts/{id}` | `stores[]` (magasin, lignes, total) ; PATCH `{"status": "draft" \| "in_progress" \| "done", "usage"?}` ; `done` crée les entrées (`cart:<id>:<ligne>`) |
| PATCH | `/api/shopping-carts/{id}/lines/{lineId}` | `{"checked"?, "quantity"?}` |
| GET | `/api/shopping-carts/{id}/text` | La liste en texte brut, à partager (avec l'EAN) |
| GET | `/api/shopping-carts/{id}/store-carts` | Paniers pré-remplis des magasins qui ont un connecteur (Amazon) : `[{store, urls[], lineCount, skipped[]}]` |
| GET | `/api/shopping-carts/{id}/purchase-orders` | Bons de commande envoyés pour ce panier (`supplier`, `recipient`, `sentBy`, `sentAt`, `messageId`, `status` queued \| demo) |
| GET | `/api/shopping-carts/{id}/purchase-orders/{supplierId}/preview` | Aperçu (rien n'est envoyé) : `to`, `subject`, `text`, `htmlBody`, `estimatedTotal`, `alreadySent` ; 422 sans `orderEmail` ou sans ligne |
| POST | `/api/shopping-carts/{id}/purchase-orders/{supplierId}` | STOCK_MANAGE, une personne : `{"confirm": true}` obligatoire (422 sinon) ; envoi par Rocket Mailer (`X-Impersonate-User` = vous, `Idempotency-Key` `po:<panier>:<fournisseur>`) ; 201, ou 200 avec le bon déjà envoyé |

Champs de commande : article `ean` (EAN-13/8 validé) ; magasin `orderEmail`, `searchUrlTemplate` (`{ean}` / `{name}`), `amazon`, `amazonDomain` ; offre `asin`, `productUrl` ; ligne de panier `item.ean`, `asin`, `productUrl`.
